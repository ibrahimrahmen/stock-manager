Synchronisation Navex
Marquer les commandes livrées (statut LIVREE)
Recherche les commandes locales en statut Confirmée mais dont Navex dit qu'elles ont été Livrées. Les fait passer au statut "Livrée" (vert).
Réparer les commandes "Supprimées" chez Navex
Recherche les commandes locales en statut Confirmée mais dont Navex dit qu'elles ont été Supprimées. Les fait passer au statut "Supprimé Navex" avec badge rouge.
Recalculs
Recalculer le total de toutes les commandes
Recalcule Order.total = somme offres + livraison − remise pour toutes les commandes. Utile pour réparer les commandes anciennes qui avaient un total à 0 à cause d'un bug.
Réparer les articles non reliés à leur offre (avant/arrière)
Répare les commandes où la liste d'articles (à l'avant) et l'éditeur d'offre (à l'intérieur) ne montrent pas la même chose — les pièces existent mais n'ont jamais été reliées à leur offre, donc la couleur / taille apparaissent vides dans l'éditeur (ex : commande #22271). Relie chaque pièce à son offre. Sûr : ne crée, ne supprime et ne fusionne jamais un article en trop, ne réduit jamais le total, et ne touche pas une commande verrouillée si le total changerait.
Fais d'abord le Dry-run pour voir la liste.
Boutique Shopify (Barats.tn)
Rattraper les commandes Shopify manquées
Récupère les commandes de la boutique Shopify (14 derniers jours) et crée celles qui manquent dans le système — utile quand des commandes du site n'ont pas pu être enregistrées (ex : base de données pleine). Idempotent : ne touche jamais une commande déjà présente.
Fais d'abord le Dry-run pour voir combien manquent.
Unifunl (agent IA → commandes)
Importer les commandes Unifunl
Récupère les commandes captées par l'agent IA Unifunl (chats Messenger / Instagram / WhatsApp) et crée celles qui manquent dans le système, en statut Non confirmée pour validation. Idempotent : ne recrée jamais une commande déjà importée. Normalement automatique (cron) ; ce bouton sert à tester ou rattraper.
Fais d'abord le Dry-run.
Activer les échos de messages (conversation complète)
Abonne vos pages Messenger/Instagram au champ message_echoes pour que Meta vous envoie AUSSI les réponses sortantes de la page (ex : celles d'Unifunl) — ainsi votre système garde la conversation complète, pas seulement les messages du client.
Fais d'abord le Dry-run pour voir l'état actuel de chaque page.
Note : le champ « message_echoes » doit aussi être coché dans le tableau de bord Meta (App → Webhooks) pour que la livraison marche.
RGPD — Suppression de données (demande Meta)
Supprimer les données d'utilisateurs (IDs Meta)
Colle les identifiants (PSID) fournis par Meta (un par ligne). Supprime leur conversation, dissocie l'ID du client, et efface la transcription enregistrée sur leurs commandes. Les commandes elles-mêmes sont conservées.
Fais d'abord le Dry-run.
Base de données — Nettoyage
Vider les vieilles conversations (libérer de l'espace)
Efface uniquement le texte des conversations Messenger / Instagram de plus de 10 jours. Aucune commande n'est supprimée — seul le texte du chat est vidé. Réduit la taille de la base de données.
Fais d'abord le Dry-run.
